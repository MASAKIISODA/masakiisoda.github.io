Privacy Policy

Last updated: November 7, 2026

This policy applies to the Google OAuth client named "rclone". The client is used only by its owner, with the open-source tool rclone, to back up and sync the owner's own files with the owner's own Google Drive.

What data is accessed

Files and file information (such as names, sizes and dates) in the owner's own Google Drive. They are accessed only to copy files between the owner's computer and Google Drive.

How data is used and shared

  • No data is collected by, or sent to, any server operated by the developer.
  • No data is sold, shared with, or transferred to any third party.
  • No data is used for advertising, analytics, or training of any model.
  • Authorization tokens are stored only on the owner's own computer.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account page: myaccount.google.com/permissions.
